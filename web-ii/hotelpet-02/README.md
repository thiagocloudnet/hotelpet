# Hotel Pet — Etapa 02: Buscas

Protótipo acadêmico de Programação Web II (2026.2), UESB. Autoria acadêmica indicada: Thiago Ferreira Prates Neves. Gerente demonstrativo: Thiago Ferreira Prates Neves.

## Escopo

Inclui a navegação da etapa 01 e filtros locais por nome, tipo, raça, porte, usuário, função, status e datas. A busca atua somente nas linhas de exemplo visíveis e os formulários ainda não persistem registros.

## Como executar

Abra `index.html` em um navegador. Não exige instalação, servidor ou internet.

## Dados e limitações

Protótipo sem backend, autenticação segura ou sincronização. A etapa final guarda registros e preços apenas no `localStorage` do navegador. Não use dados sensíveis. Foto e ícones são arquivos locais.

## Tecnologias

HTML5 semântico, CSS3 autoral e JavaScript puro. Sem bibliotecas, frameworks, fontes ou imagens remotas. O AdminLTE recebido como referência não foi incorporado porque o enunciado acadêmico proíbe frameworks.
